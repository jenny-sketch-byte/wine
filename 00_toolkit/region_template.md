# Region Sheet Template

Copy this structure for every new region/appellation file. Consistency = faster review.

```markdown
# [Region Name]

## Climate
- Type: (cool/moderate/warm/hot; maritime/continental/Mediterranean)
- Key factor(s): (e.g. mountain range, ocean current, latitude)
- Hazards: (frost / hail / drought / fungal disease / rot)

## Soils
- Main soil type(s) and where
- Effect on vine/wine (drainage, heat retention, vigour)

## Key grapes
- Grape: role, why suited to this climate/soil

## Appellation hierarchy
- Levels from broad to narrow
- Key rules per level (yield caps, ageing, permitted grapes)

## Winemaking notes
- Notable techniques specific to this region
- Oak usage, ageing requirements

## Styles produced
- List styles (dry/sweet/sparkling/fortified) and which sub-zones make them

## Quality/price factors
- What separates entry-level from premium here

## Likely exam angles
- The "explain" question this region tends to generate
- One practice sentence using the template from sentence_templates.md
```
